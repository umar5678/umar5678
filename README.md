## How I work

1. I write what the software must do before any code exists.

2. Tests come from that spec and the API contract, not from the code an agent wrote.

3. Checks pass or fail on their result, not on what anyone reports.

4. Every mistake I catch becomes a permanent check, so it costs once.

How this works in practice, including the time my own checker lied: [How I check software that AI wrote](https://umarfarooq.io/projects/verifying-ai-built-software).
